# Picobo

台灣繁體中文的匹克球（Pickleball）規則教學與球場工具。

**學規則**：用球場示意圖一步一步看懂發球、雙彈跳、廚房、計分與站位，包含正統的
側出計分、每球得分制，以及六種常見趣味玩法。

**上場用**：視覺化計分板（顯示誰該在哪裡發球）、抽籤分組與輪轉排程。手機優先，
離線可用，不需要帳號。

## 執行

純 HTML / CSS / JavaScript，不需要安裝任何東西：

```
python3 -m http.server 8080
```

然後開啟 http://localhost:8080 。

## 測試

```
node --test
```

## 規則來源

正統規則以 USA Pickleball Official Rulebook 現行版為準。各球場做法不同的玩法會
在頁面上標明。
